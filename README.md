
# CodeAlpha Frontend Development Projects

This repository contains two frontend development projects built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship tasks.

## Projects

### Task 1: Image Gallery

A modern, responsive image gallery designed to display beautiful photographs with interactive features.

**Features**
- Responsive grid layout for different screen sizes.
- Image hover effects and smooth transitions.
- Category-based image filtering.
- Lightbox view for enlarged images.
- Next and previous image navigation.
- Keyboard navigation using arrow keys.
- Close the lightbox using the Escape key.
- Modern dark theme and attractive user interface.

**Technologies Used**
- HTML5
- CSS3
- JavaScript

**Folder Structure**

```text
ImageGallery/
├── index.html
├── style.css
└── script.js
```

### Task 2: Smart Calculator

A stylish and interactive calculator that performs basic arithmetic operations with keyboard support.

**Features**
- Addition, subtraction, multiplication, and division.
- Percentage calculations.
- Decimal number support.
- Clear all and delete last character functions.
- Positive and negative number toggle.
- Real-time display updates.
- Keyboard input support.
- Error handling for invalid calculations.
- Responsive design with a modern dark interface.

**Technologies Used**
- HTML5
- CSS3
- JavaScript

**Folder Structure**

```text
SmartCalculator/
├── index.html
├── style.css
└── script.js
```

## Installation and Setup

### Prerequisites

- Visual Studio Code or any code editor.
- A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.
- Live Server extension for VS Code (recommended).

### Steps to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to the project you want to run.
4. Open `index.html` using Live Server.
5. Explore the application's features in your browser.

Both projects can run directly in a browser without installing additional JavaScript packages.
